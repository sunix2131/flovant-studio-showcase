# Flovant

Дизайн и разработка сайтов.

![Flovant](media/flovant-cover.png)

[Посмотреть презентацию ↗](https://github.com/sunix2131/flovant-studio-showcase/raw/refs/heads/main/media/videos/flovant-presentation-16x9.mp4) · [Вертикальный ролик ↗](https://github.com/sunix2131/flovant-studio-showcase/raw/refs/heads/main/media/videos/flovant-promo-9x16.mp4)

Мы — Flovant, ИТ-студия. Делаем сайты для компаний, интернет-магазины и приложения в Telegram. Берём на себя дизайн, разработку и запуск. Когда проекту нужны личный кабинет, CRM или онлайн-оплата, подключаем их к сайту.

Работу показываем по ходу разработки: даём ссылку, по которой можно открыть сайт, всё попробовать и обсудить правки. После запуска передаём доступы и объясняем, как обновлять страницы и работать с заявками.
